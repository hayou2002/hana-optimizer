> **形态说明**：`references/rules/` 即本 skill 的规范副本，自包含可用。
> 项目开发仓库另存 `docs/`（源，不随发布）；两者冲突以**仓库源 + 现场实测**为准（使用者只需看内置副本）。

## 三部分结构

```
调查（01/02/03/06） → 策略（04/05/07） → 自动化（08）
认识对象 → 制定怎么动 → 让它按节奏发生
```

## 用词统一（防误解）

- **反悔区**＝工作区软删落点 `_temp/反悔区/{YYYYMMDD}/`（04 管）；本体 `trash/` 是另一物、**无 TTL**。
- **三档方案**＝可现清 / 需确认 / 绝不碰。
- **体检四口径**＝可释放 / 待归位 / 仅报告 / 绝不碰。（"待裁决"是**禁用词**）
- **待办裁决列表**＝Agent 判不了风险的**动作项**清单（≠ inbox 里的文件）。
